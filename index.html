数据管理

所有数据保存在本浏览器 localStorage 中，不会上传到任何服务器。建议定期导出备份，或用于在另一台设备上继续使用。

计算公式速览

  • C1 思想品德表现 = min(100, 80 + 加分 − 减分)，合格线 60。
  • C2 课程学习成绩 = Σ(考分 × 学分) / Σ学分（学分加权平均分）。
  • C3 发展素质 = min(100, 70 + 各类加分)。
  • 学年综合测评成绩 C = C1×10% + C2×70% + C3×20%。
  • 在校综合测评成绩 = 各学年综合测评成绩的平均值。
