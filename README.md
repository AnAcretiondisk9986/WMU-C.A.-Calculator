# 学生素质综合测评计算器（含转专业考核计算）

基于 GitHub Pages 的纯前端静态网页（零依赖、零构建），依据《学生素质综合测评办法》实现综测计算，并配套独立的**转专业考核计算器**页面。

> 注意：仅供学生自评参考，测评结果以班级测评小组、系及学院认定为准；各系实施细则可能调整指标与分值。

## 功能

- **双测评方案**：页头**分段单选**切换**温医大本部**（默认）或**仁济学院**，评分表、基准分、体测文案随方案切换（本部 C3 基准 65 分，仁济 70 分）；选择自动记忆，下次打开沿用上次状态
- **个人测评**：按学年录入
  - **C1 思想品德表现**：基准分 80，加减分累计，最高 100 分；低于 60 分提示不合格
  - **C2 课程学习成绩**：学分加权平均分 C2 = Σ(考分×学分) / Σ学分；每门课可选**百分制/五级制**（优=90 良=80 中=70 及格=60 不及格=50，切换自动换算）；**支持教务成绩粘贴导入**（教务系统复制表格→粘贴解析）与**豆包批量导入**（内置引导卡片：截图→豆包 OCR→复制回本站粘贴，提供一键复制的鲁棒提示词）；课程性质标记 + "仅统计必修+限选"开关（教务口径，排除任选课）；补考按 60 分、重修按最高分计入；自动统计不及格学分并提示"≥20 学分不合格"；也可**直接填写 C2 成绩**（如已有教务系统加权分，填写后以手动值为准）
  - **C3 发展素质**：只加分，最高 100 分；分学习能力、社会活动与社会工作、创新创业成果、文体素质四类
  - **体质测试判定**：输入体测总分并勾选是否保健班（本部为"保健科证明"），自动显示红/绿降档提示（依据《奖学金实施办法》：未达良好 ≥80 分者按降一等级评定，保健班不予降档）
  - **学年综合成绩** C = C1×10% + C2×70% + C3×20%；也支持**直接填写本学年总分**（如已有学院/班级评定结果，填写后以手动值为准，清空恢复自动计算）
- **快捷添加**：表 1~表 7 全部做成快选（学科竞赛、文体竞赛等为"级别×等级"矩阵），已按 20-21、23-24 学年测评会议纪要更新加分细则（班长/团支书 3 分、优秀心理委员降一级、全国百强社团、浙江省青年志愿服务项目、星级评定等），也支持自由录入
- **班级排名**：录入姓名+总分自动降序排名，同分并列
- **在校综合成绩**：各学年综合成绩的平均值
- **数据持久化**：自动保存到浏览器 localStorage；支持 JSON 导出/导入备份
- **个人档案卡**：把当前数据保存为一张命名「档案卡」，随时载入/导出/删除，支持导入他人分享的档案卡 JSON；载入后改动可一键「同步到当前档案」写回；页头「档案卡」与「数据管理」页均可打开，适合多位同学共用设备或分阶段备份
- 支持多学年、学年重命名/删除

## 转专业考核计算（transfer.html）

导航栏"转专业计算 ↗"进入独立平行页面，同样区分**本部 / 仁济**：

- **本部**：按接收学院切换 13 个学院的《选拔类转专业考核实施办法》（2024-12-30 印发），自动匹配该学院的
  - 专业成绩排名公式（含各专业不同系数，如第一临床 0.15/0.3/0.5、口腔 0.3、护理分档制等）
  - 面试满分与合格线（精神医学面试 <18 分不予录取）
  - 大学英语计分表（10 种规则，覆盖四六级、眼视光雅思/托福、口腔/药学等特殊分档）
  - 专长档次（各学院不同分值与档数，含仁济 1.5 分档）
  - 高考成绩计分（门槛式 5/10 分、口腔公式 `10−[(最低录取分−高考)×0.25]`）
  - 跨专业计分（眼视光：非医→医 0 分）
- **仁济**：2025 年转专业统一方案（成绩 65% / 面试 25% / 专长 5% / 英语 5%），并判定第一轮（前 15%）、第二轮（前 50%）申请资格
- 实时输出综合成绩与分项明细，并按排名占比判定申请资格（含眼视光总分门槛 75/60 分）

## 部署到 GitHub Pages

1. 在 GitHub 新建仓库（如 `wmu-zongce`），把本目录文件推上去：
   ```bash
   git init
   git add .
   git commit -m "综测计算器 v1.0"
   git branch -M main
   git remote add origin https://github.com/<你的用户名>/wmu-zongce.git
   git push -u origin main
   ```
2. 仓库页面 **Settings → Pages → Source** 选择 `Deploy from a branch`，分支选 `main`，目录选 `/ (root)`，保存。
3. 等待 1~2 分钟后访问 `https://<你的用户名>.github.io/wmu-zongce/`。

> 也可直接本地双击打开 `index.html` 使用（数据保存在本机浏览器）。

```
js/transfer.js      转专业考核数据与纯计算（本部13学院 + 仁济）
js/transfer-app.js  转专业页面交互逻辑
test/calc.test.js   综测计算层单测（Node）
test/transfer.test.js  转专业计算层单测（Node）
```


## 计算规则速览

| 部分 | 公式 | 封顶/合格 |
|---|---|---|
| C1 思想品德 | min(100, 80 + Σ加分 − Σ减分) | <60 不合格 |
| C2 课程成绩 | Σ(考分×学分)/Σ学分 | 不及格学分≥20 不合格 |
| C3 发展素质 | min(100, 基准分 + Σ加分)，基准分：本部 65 / 仁济 70 | — |
| 学年综合 C | C1×10% + C2×70% + C3×20% | — |
| 在校综合 | 各学年 C 的平均值 | — |
