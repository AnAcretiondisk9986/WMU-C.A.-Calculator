# 学生素质综合测评计算器

基于 GitHub Pages 的纯前端静态网页（零依赖、零构建），依据《学生素质综合测评办法》实现。

> ⚠️ 仅供学生自评参考，测评结果以班级测评小组、系及学院认定为准；各系实施细则可能调整指标与分值。

## 功能

- **双测评方案**：页头下拉选择**温医大本部**（默认）或**仁济学院**，评分表、基准分、体测文案随方案切换（本部 C3 基准 65 分，仁济 70 分）
- **个人测评**：按学年录入
  - **C1 思想品德表现**：基准分 80，加减分累计，最高 100 分；低于 60 分提示不合格
  - **C2 课程学习成绩**：学分加权平均分 C2 = Σ(考分×学分) / Σ学分；每门课可选**百分制/五级制**（优=90 良=80 中=70 及格=60 不及格=50，切换自动换算）；**支持教务系统截图 OCR 导入**（截图→识别→按文字坐标重建表格，识别结果可预览修改后导入；基于 Tesseract.js，首次使用需联网下载中文包）与**粘贴文本导入**（备用）；课程性质标记 + "仅统计必修+限选"开关（教务口径，排除任选课）；补考按 60 分、重修按最高分计入；自动统计不及格学分并提示"≥20 学分不合格"
  - **C3 发展素质**：只加分，最高 100 分；分学习能力、社会活动与社会工作、创新创业成果、文体素质四类
  - **体质测试判定**：输入体测总分并勾选是否保健班（本部为"保健科证明"），自动显示红/绿降档提示（依据《奖学金实施办法》：未达良好 ≥80 分者按降一等级评定，保健班不予降档）
  - **学年综合成绩** C = C1×10% + C2×70% + C3×20%
- **快捷添加**：表 1~表 7 全部做成快选（学科竞赛、文体竞赛等为"级别×等级"矩阵），已按 20-21、23-24 学年测评会议纪要更新加分细则（班长/团支书 3 分、优秀心理委员降一级、全国百强社团、浙江省青年志愿服务项目、星级评定等），也支持自由录入
- **班级排名**：录入姓名+总分自动降序排名，同分并列
- **在校综合成绩**：各学年综合成绩的平均值
- **数据持久化**：自动保存到浏览器 localStorage；支持 JSON 导出/导入备份
- 支持多学年、学年重命名/删除

## 部署到 GitHub Pages

1. 在 GitHub 新建仓库（如 `wmu-zongce`），把本目录文件推上去：
   ```bash
   git init
   git add .
   git commit -m "综测计算器 v1.0"
   git branch -M main
   git remote add origin https://github.com/<你的用户名>/wmu-zongce.git
   git push -u origin main
   ```
2. 仓库页面 **Settings → Pages → Source** 选择 `Deploy from a branch`，分支选 `main`，目录选 `/ (root)`，保存。
3. 等待 1~2 分钟后访问 `https://<你的用户名>.github.io/wmu-zongce/`。

> 也可直接本地双击打开 `index.html` 使用（数据保存在本机浏览器）。

## 目录结构

```
index.html          页面骨架
css/style.css       样式
js/data.js          评分表数据（表1~表7、加减分项目、五级换算）
js/calc.js          纯计算逻辑（C1/C2/C3/总分/排名）
js/storage.js       localStorage 持久化 + JSON 导入导出
js/app.js           交互逻辑（渲染、快捷添加面板、班级排名）
test/calc.test.js   计算层单测（Node）
```

## 本地开发与测试

```bash
# 计算层单测（无需安装依赖）
node test/calc.test.js

# 如需运行 DOM 冒烟测试（可选，需要 jsdom）
npm install jsdom --no-save   # 在临时目录安装
node smoke.test.js
```

## 计算规则速览

| 部分 | 公式 | 封顶/合格 |
|---|---|---|
| C1 思想品德 | min(100, 80 + Σ加分 − Σ减分) | <60 不合格 |
| C2 课程成绩 | Σ(考分×学分)/Σ学分 | 不及格学分≥20 不合格 |
| C3 发展素质 | min(100, 基准分 + Σ加分)，基准分：本部 65 / 仁济 70 | — |
| 学年综合 C | C1×10% + C2×70% + C3×20% | — |
| 在校综合 | 各学年 C 的平均值 | — |
